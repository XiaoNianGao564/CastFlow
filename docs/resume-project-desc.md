# CastFlow 简历项目描述

---

**CastFlow —— 自迭代多智能体时序预测平台**

**项目角色**：独立设计开发（全栈） | **技术栈**：TypeScript · Bun · Hono · SolidJS · Python · MySQL · Qwen · SSE

针对电力负荷预测中模型选择依赖经验、调参效率低的问题，独立设计了一套多智能体自迭代预测系统。采用自研编排器（非LangChain）调度12个专用Agent，支持4种编排模式，覆盖数据诊断→代码生成→沙箱执行→误差评估→LLM补丁→迭代收敛的完整闭环，应用于铜川市五区县电量负荷预测。

**核心工作：**

1. **自研编排与多Agent协作**：设计Coordinator调度12个Agent（数据/代码生成/执行/评估/分析/补丁/模型选择等），实现Full Loop、ReAct动态规划（11工具）、3-Agent温度分层流水线（0.3/0.6/0.2）、并行模式四种编排策略；

2. **代码级自迭代优化**：LLM生成最小化代码补丁（仅改参数/预处理/模型结构），结合确定性正则修复（<1ms，减少90%+ LLM调用）、空补丁检测（连续3次触发兜底）与最优版本回滚，实现低成本高稳定的自动优化；

3. **智能模型选择**：基于数据6维特征（季节性/趋势/波动性等）为31个模型池动态打分，支持Top-3并行预测与迭代，取全局最优；

4. **三层记忆系统**：ExperienceStore（有效/无效策略）+ SkillStore（数据-策略指纹匹配）+ RAGStore（TF-IDF语义检索），实现跨会话经验沉淀复用；

5. **实时监控Dashboard**：SolidJS + SSE流式推送迭代日志、准确率趋势图与区县级对比视图，一键启动端到端闭环。

**成果**：准确率从基线持续收敛至90%+，LLM调用成本降低90%，端到端自动化运行零人工干预。
